# Colección de Recursos by Sudo

Hola! Este repo está creado con la intención de tener una colección de diversos
recursos repartidos por la web, ya sean de acceso libre y/o, completamente gratis,
de temas relacionados con la tecnología, desde historia, documentación, proyectos, 
tutoriales, etc. 

El Repo está dividido por Lenguaje/Framework, Historia, Artículos Científicos, Sitios de Interés (como Youtube o W3Schools) y Comunidades. Si buscas sobre alguno de estos temas en particular, te invitamos a buscar en la sección adecuada. 

Este es repo para todxs, por lo que si encuentras algún link caido y/o quieres añadir
al mismo, eres libre de crear una PR y el equipo de Sudo la revisará para poder añadirla. 

> [!IMPORTANT]  
> El contenido que desees agregar (y el que se encuentra aqui) no debe infrigir derechos de copyright. Lo que aqui se encuentra son links que se saben cuentan con los permisos del autor de compartir y/o se encuentran en sitios de consulta permitidos. 

> [!NOTE]
> Cuidado con las licencias del contenido que compartas. Verifica que se puede hacer y que no. Cualquier duda puedes preguntar al creador y/o puedes hacer un Issue preguntando por el mismo.

## Python

- [AprendePython.es](https://aprendepython.es/) Una paǵina en español con bastantes gráficos sobre como es usar el lenguaje. 

- [Reflex](https://github.com/reflex-dev/reflex). Una libreria para hacer WebApps con Python.  

- [Flet](https://github.com/flet-dev/flet). Una librería para hacer programas multiplataforma con Python. Basada en Flutter.

- [Awesome for Beginners by MunGell](https://github.com/MunGell/awesome-for-beginners). Un Repo de Proyectos aptos para principiantes de cualquier lenguaje. 

- [Awesome Selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted) Un Repo con una lista de programas gratuitos para servicios web o de red autoalojados. 

- [Free For Dev](https://free-for.dev/#/). Una lista de servicios casi y totalmente gratuitos para programadores. 

- [Code Report](https://www.youtube.com/@code_report). Un canal dedicado a mostrar soluciones a problemas de programación competitiva y sobre particularidades de algunos lenguajes de programación. 

- [MoureDev](https://www.youtube.com/@mouredev). Un canal dedicado a enseñar como crear aplicaciones Web, Android e iOS con Python, Kotlin, Swift, etc. 

- [MiduDev](https://www.youtube.com/@midudev). Canal dedicado a la enseñanza de Programación Web Full Stack. 

- [Linux](https://github.com/torvalds/linux). El que es posiblemente el repo más importante de la historia: el kernel de Linux.

- [DevDocs](https://devdocs.io/). Una página que concentra la documentación de muchos lenguajes y frameworks en un solo sitio, inclusive dividiendola en versiones de c/u. 

- [Misbrands by mkrl](https://github.com/mkrl/misbrands). Una colección de stickers "erroneos" de varios lenguajes, frameworks y más. 

- [Gogh](https://github.com/Gogh-Co/Gogh). Una colección de paletas de colores que puedes usar en la terminal y en otros lados. 

- [FreeCodeCamp](https://www.freecodecamp.org/) La Organización más grande a nivel mundial enfocada en enseñar código de manera gratuita.
